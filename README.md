# Open Yuanbaotong

园宝通家长端的非官方开源 Web 客户端。界面按 Android 家长 App 的布局、配色和图标还原，保留「家园」「时光轴」「我的」，不包含好学堂和印品屋。

React + Vite + Tailwind CSS + shadcn/ui。构建产物为纯静态资源；Vercel 外部 rewrites 转发官方接口，无自建后端、数据库或 Serverless Function。

## 使用

使用已有园宝通账号的手机号和短信验证码登录。宝宝信息来自官方家长账号接口，可在宝宝头像或宝宝管理中切换。

- 家园：官方横幅、成长档案制作与预览、亲子任务、今日美食、下周食谱、园所菜单、通知及待办。
- 时光轴：亲友圈、班级圈、园所/班级/家长分类、动态详情、评论、点赞、日期筛选、亲友圈内容搜索、童言童语、大事记、日记、宝贝相册。
- 图片：列表缩略图、缓存小图立即预览、按屏幕加载清晰预览、左右切换、触屏滑动、放大、按需查看和下载原图。下载保留服务器文件字节，不经过 Canvas 重绘或重新压缩。
- 发布：照片视频、日记、音频文件、大事记；发布前展示谁可以看。上传使用官方接口签发的临时七牛凭据和[官方浏览器 SDK](https://developer.qiniu.com/kodo/1283/javascript)。
- 我的：宝宝信息与添加宝宝、亲友团、关联另一位家长、消息、订单列表、个人资料、收货地址、意见反馈、帮助中心、退出登录。

浏览器版本仍有边界：成长档案支持家长页照片替换、本地选图、照片裁剪位置与旋转、文字内容和字体编辑、元素移动、撤销/重做、逐页预览，以及通过官方接口保存图层与新缩略图。保存前检查其他设备的修改，保存后回读核对。模板库换页、贴纸库、评量表专用编辑与批量应用尚未适配；订单支付、缴费管理、原生直播 SDK、账号安全设置及亲友权限调整仍需使用原 App。不会将这些入口伪装成可操作的网页功能。

上游接口并非公开的稳定 API。列表、详情、空数据和错误信息都来自官方服务；学校未开通的项目会显示官方提示。发布、评论、修改资料等会写入本人园宝通账号，应由使用者自行操作。

## 开发与部署

```sh
npm ci
npm run dev
npm run check
npm run build
```

在 Vercel 导入仓库，Framework Preset 选 Vite。配置已指定构建命令 `npm run build` 和目录 `dist`。使用 Node.js 22 或更新版本。不需要设置账号、密码或 API Key 环境变量。

本地 Vite 仅提供静态页面；官方接口需在已应用 `vercel.json` rewrite 的 Vercel 环境使用。

## 数据与许可

登录凭据保存在当前域名的 `localStorage`，关闭页面后仍保留，退出登录或凭据过期后清除；旧版当前标签页的凭据会自动迁移。验证码不持久保存。账号响应不进入源码、静态构建或服务端数据库。代码不加入第三方统计、会话回放或请求日志；上传 SDK 的统计上报已关闭。

转发仅允许配置中列出的官方服务和媒体域名，无任意 URL 代理。API 响应设置 `private, no-store`。部署者的 Vercel 项目会转发请求给园宝通，因此应使用可信部署或自行部署。

源代码采用 MIT 许可。`public/app-assets/` 的官方 UI 素材版权属于原权利人，不适用 MIT；见 `THIRD_PARTY_LICENSES.md`。仓库不包含 APK、反编译代码、登录凭据、儿童照片或个人账号数据。本项目与园宝通及其开发商无关联。
